# 基金数据查看应用 - 项目计划

## 1. 项目概述

本项目是一个轻量级的基金数据查看Web应用，旨在帮助用户快速查看基金（股票）数据。应用采用极简设计风格，注重信息密度和视觉舒适度。

## 2. 技术选型

| 分类 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 前端框架 | React | 18+ | 现代前端框架，组件化开发 |
| 构建工具 | Vite | 6+ | 快速构建工具，支持热更新 |
| 样式方案 | TailwindCSS | 3+ | 原子化CSS，快速开发响应式布局 |
| 图标库 | Lucide React | 最新 | 轻量级图标库 |
| 路由管理 | React Router DOM | 6+ | 单页应用路由管理 |
| 数据存储 | LocalStorage | - | 本地存储基金配置 |

## 3. 数据来源

### 3.1 基金数据 API

- **天天基金网** (`fund.eastmoney.com`)
  - 基金净值数据
  - 基金持仓股票数据
  - 实时估值数据

### 3.2 股票数据 API

- **东方财富网** (`eastmoney.com`)
  - 股票实时行情
  - 涨跌幅数据

### 3.3 API 接口说明

| 接口 | URL | 说明 |
|------|-----|------|
| 基金持仓 | `http://fund.eastmoney.com/pingzhongdata/{fundCode}.js` | 获取基金持仓信息 |
| 股票行情 | `http://push2.eastmoney.com/api/qt/stock/get` | 获取股票实时行情 |

## 4. 功能需求

### 4.1 页面结构

| 页面 | 路径 | 说明 |
|------|------|------|
| Dashboard | `/` | 默认主页面，展示基金卡片 |
| Admin | `/admin` | 基金管理页面 |
| Login | `/login` | 预留登录页（不开发） |

### 4.2 顶栏设计（参考UI图）

- 高度：20-30px
- 左侧：Logo/应用名称
- 中间：搜索框（搜索基金名称/代码）
- 右侧：导航切换（Dashboard/Admin）、刷新按钮

### 4.3 Dashboard - 基金卡片展示（参考UI图）

- 布局：4列网格布局，一页至少显示16个基金（4x4）
- 卡片样式：
  - 圆角设计
  - 背景色根据涨跌决定：
    - 上涨：浅绿色渐变
    - 下跌：浅红色渐变
    - 持平：浅黄色渐变
- 卡片内容：
  - 基金名称
  - 基金代码
  - 最新净值
  - 涨跌幅（带颜色指示）
  - Top10持仓股票实时涨跌（迷你列表）

### 4.4 Admin - 基金管理

- 基金列表管理：添加/删除基金
- 排序设置：自定义显示顺序（拖拽排序）
- 布局设置：网格列数调整（3/4/5列）
- 数据持久化：配置保存到 LocalStorage

### 4.5 数据刷新

- 支持手动刷新数据（顶部刷新按钮）
- 自动刷新（可配置，默认关闭）

## 5. UI设计规范（参考UI图）

### 5.1 色彩方案

| 状态 | 颜色 | 用途 |
|------|------|------|
| 上涨 | 浅绿色渐变 (#d1fae5 -> #a7f3d0) | 卡片背景、正收益 |
| 下跌 | 浅红色渐变 (#fee2e2 -> #fecaca) | 卡片背景、负收益 |
| 持平 | 浅黄色渐变 (#fef3c7 -> #fde68a) | 卡片背景 |
| 文字 | 深灰色 (#1f2937) | 主要文字 |
| 次要文字 | 中灰色 (#6b7280) | 辅助文字 |

### 5.2 布局规范

- 顶栏高度：28px
- 卡片间距：8-12px
- 卡片圆角：12px
- 网格列数：默认4列，可配置

## 7. 开发计划

### 7.1 步骤

1. **初始化项目**：使用 Vite 创建 React 项目
2. **安装依赖**：TailwindCSS 3、Lucide React、React Router DOM
3. **配置 TailwindCSS**：设置主题和基础样式
4. **创建 API 服务**：封装数据请求函数
5. **创建工具 Hook**：useLocalStorage
6. **创建组件**：Header、FundCard、StockMini、Layout
7. **创建页面**：Dashboard、Admin
8. **配置路由**：App.jsx 设置路由
9. **添加 Mock 数据**：用于开发测试
10. **测试与优化**：确保功能正常

### 7.2 风险评估

| 风险 | 描述 | 应对方案 |
|------|------|----------|
| API 限流 | 频繁请求可能被封IP | 添加请求节流、缓存机制 |
| API 接口变更 | 第三方接口可能变更 | 预留接口适配层，便于切换 |
| 跨域问题 | 前端直接请求可能跨域 | 使用代理或服务端转发 |

## 10. Git 提交规范

### 10.1 提交原则

每次明确的任务完成后都应该成为一个独立的 Git commit，便于代码管理和版本回溯。

### 10.2 提交信息格式

```
<类型>: <简短描述>

<详细描述（可选）>
```

### 10.3 提交类型

| 类型 | 说明 |
|------|------|
| `feat` | 新增功能 |
| `fix` | 修复 bug |
| `style` | 样式调整（不影响逻辑） |
| `refactor` | 代码重构 |
| `docs` | 文档更新 |
| `chore` | 构建/工具配置 |
| `test` | 测试相关 |

### 10.4 提交示例

```
feat: 添加基金卡片组件
- 实现基金卡片UI展示
- 添加涨跌颜色渐变
- 显示持仓股票列表

fix: 修复搜索过滤功能
- 修正搜索关键词匹配逻辑
- 优化搜索性能

style: 调整顶栏高度为28px
```

### 10.5 分支管理

- `main`：主分支，稳定版本
- `dev`：开发分支，日常开发
- `feature/*`：功能分支，开发新功能
- `fix/*`：修复分支，修复 bug
